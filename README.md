# 征途 · 二万五千里

纪念中国工农红军长征胜利九十周年 · 主题报道 H5

> 以「铁流·丰碑」主题文献展的七十余件展品为线索，从于都河到会宁城，重走二万五千里。

---

## 一、这是什么

一个可以离线打开的单页 H5 长报道，纯前端、零依赖、零外部请求。

- 七个部分 + 序 + 结语：出发 / 转折 / 雪山草地 / 会师 / 记录 / 从会师到开国 / 展品档案
- 13 张展品实拍照片全部内联在 HTML 里，单独拷走也能看
- 交互：目录抽屉、三档字号、图片灯箱、档案横滑、章节胶囊、进度条、数字滚动

## 二、文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | **主文件**，约 2.4 MB，图片全部以 base64 内联，可离线单独打开 |
| `index-external.html` | 排版源文件，图片用相对路径引用 `assets/img/`，改样式改内容改这个 |
| `assets/img/` | 13 张展品照片原图（已按内容重命名） |
| `preview.png` | 六屏预览拼图，用于投稿/展示 |
| `创意方案.md` | AIGC 创意作品概念方案（题目、立意、形式、素材清单、工具使用计划） |
| `_tools/` | 构建与截图脚本（内联打包、CDP 截图、拼图），交付时可删除 |

改完 `index-external.html` 后重新生成单文件版：

```bash
# 需要 Python + Pillow
python _tools/embed.py .            # 默认 q80 / 宽 1080
python _tools/embed.py . 72 800     # 体积优先：q72 / 宽 800（本项目用的是这组）
```

## 三、内容与史实

- 时间线：1934.10 于都出发 → 1934.11–12 湘江 → 1935.01 遵义 → 1935.01–03 四渡赤水 → 1935.05 金沙江/大渡河/泸定桥 → 1935.06 夹金山 → 1935.08 草地 → 1935.10 吴起镇 → 1936.10 会宁、将台堡会师
- 数据口径（文中已声明为「常见估算」）：中央红军出发 8.6 万余人，湘江战役后减至 3 万余人；行程二万五千里；368 天；翻越 18 座大山、跨过 24 条大河
- 引用：展览前言与结语展板文字、毛泽东《七律·长征》、《生活》杂志 1937-01-25 原标题
- 凡转引的观众留言、老红军回忆，均在正文标注「转引自展陈说明」，不冒充采访

## 五、兼容与无障碍

- 目标：iOS Safari 15+、Android Chrome 100+、桌面 Chrome/Edge/Safari
- 使用 `svh` 处理移动端地址栏高度；`env(safe-area-inset-*)` 适配刘海屏
- 尊重 `prefers-reduced-motion`：关闭视差与入场动画
- 所有图片带 `alt`；灯箱为 DOM 内切换，键盘可操作
- 打印样式：白底黑字、隐藏悬浮控件、避免章节断页
